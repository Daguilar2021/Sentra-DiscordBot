Privacy Policy and API Data Use

This page explains how Sentra handles Discord API data, bot data, and user requests. It is written to support Discord Developer Terms of Service requirements for privacy, API data sharing, retention, and deletion.

Overview

Sentra is an open-source Discord bot and web dashboard for event organization, support ticketing, team formation, verification, and server moderation. Sentra only uses Discord API data for the functionality requested by a server administrator or user.

Sentra's privacy practices do not replace or modify Discord's terms. If this policy conflicts with Discord's Developer Terms of Service, Discord's terms control.

Data We Collect

Server configuration

Guild IDs, role IDs, channel IDs, category IDs, ticket settings, team settings, moderation log settings, and moderation thresholds.

User and verification data

Discord user IDs, guild IDs, optional Discord account email from OAuth verification, verification status, event role, team membership, and optional resume data if a deployment enables it.

Ticket and team data

Ticket channel IDs, ticket owner IDs, ticket status, staff claim IDs, staff message IDs, team names, team channel IDs, team creator IDs, member IDs, and lobby message IDs.

Moderation data

When auto-moderation is enabled, Sentra may process message content, toxicity scores, detected keywords, actions taken, user IDs, guild IDs, and timestamps for moderation logs and infraction history.

How We Use Data

  • Configure Sentra features for a Discord server.
  • Create, manage, claim, close, and delete support tickets.
  • Create and manage event teams, team channels, and team membership.
  • Verify Discord users through OAuth when a server uses verification.
  • Detect, log, and act on harmful messages when moderation is enabled.
  • Maintain operational logs needed to run, debug, and secure the application.

Sentra does not sell Discord API data. Sentra does not use Discord API data for advertising or unrelated profiling.

Sharing API Data

Sentra does not share Discord API data with third parties except when necessary to operate the application, when required by law, or when a user expressly directs the operator of a Sentra deployment to share that user's data.

Service providers may include hosting providers, databases, container infrastructure, logging systems, and similar processors used by the operator of a specific Sentra deployment. Those providers may only process data as needed to provide their services.

Retention and Deletion

Sentra retains Discord API data only while it is needed for the feature that collected it, unless a longer period is required by applicable law or a server operator's lawful obligations.

  • Ticket records should be deleted or anonymized after the ticket is closed and no longer needed.
  • Team data should be deleted when a team is disbanded or no longer needed.
  • Moderation infractions should be retained only while needed for server safety and review.
  • Server configuration should be deleted when Sentra is removed from a server or the server requests deletion.
  • OAuth verification data should be updated or deleted when it is no longer required for verification.

If Sentra receives Discord API data in error, the operator should delete it promptly and provide proof of deletion if Discord requests it.

User Rights and Requests

Users may request access, correction, modification, or deletion of their Sentra data. Requests should identify the Discord account and server involved so the relevant deployment operator can locate the data.

Sentra operators should respond to deletion or correction requests promptly and in accordance with applicable privacy laws, including GDPR, UK GDPR, LGPD, CCPA, CPRA, and similar laws where they apply.

Open Source Deployments

Sentra's source code is publicly available so multiple developers and communities can run their own local or hosted bot deployments. Each self-hosted deployment is controlled by the person or organization that runs it.

If you operate your own Sentra bot, you are responsible for your deployment's Discord Developer Portal settings, privacy policy, service providers, database security, data retention, user request process, and compliance with Discord's terms and applicable privacy laws.

Contact

For privacy, deletion, or data correction requests, contact the operator of the Sentra deployment used in your Discord server. If you are using the official Sentra deployment, contact the project maintainer through the public repository.
