General Configuration

/sentra view_config

Displays the current Sentra configuration for the server, including roles, channels, categories, moderation settings, and team settings.

/sentra quick_setup

Automatically creates and configures all required Sentra resources:

  • Sentra Admin role
  • Support Team role
  • Support Tickets category
  • Hackathon Teams category
  • Sentra Staff category
  • find-teammates channel
  • support channel
  • staff-alerts channel
  • mod-logs channel

Also posts the ticket panel automatically.

Role Configuration

/sentra create_admin_role

Creates a dedicated Sentra Admin role. Members with this role can access all Sentra administrative commands.

/sentra set_ticket_support_role

Sets the role responsible for handling support tickets. Members with this role gain access to ticket-related staff channels and notifications.

Ticketing System

/sentra set_ticket_category

Sets the category where new support tickets will be created.

/sentra set_staff_channel

Sets the channel used for ticket notifications and staff alerts.

/sentra setup_tickets

Posts the ticket creation panel in the current channel, allowing users to open private support tickets.

Required Setup

  1. Configure a Ticket Category
  2. Configure a Support Role
  3. Configure a Staff Channel
  4. Run Setup Tickets

Team Formation System

/sentra set_find_teammates_channel

Sets the channel used for teammate recruitment and matchmaking.

/sentra set_team_category

Sets the category where Sentra creates team channels.

/sentra set_max_team_size

Sets the maximum number of members allowed in a team.

Allowed Range: 2–10 members.

Moderation System

/sentra set_mod_channel

Sets the moderation log channel and enables Sentra's automated moderation system.

/sentra set_toxicity_threshold

Adjusts moderation sensitivity.

  • 0.0 = Very Strict
  • 1.0 = Very Lenient
  • Recommended: 0.7

/sentra view_infractions

Displays a user's recent moderation history, including toxicity scores, actions taken, timestamps, and detected keywords.

Permissions

Sentra administrative commands can only be used by:

  • Server Owner
  • Discord Administrators
  • Members with the Sentra Admin role

Recommended Setup Order

  1. 1 /sentra quick_setup
  2. 2 Assign Sentra Admin role
  3. 3 Assign Support Team role
  4. 4 /sentra view_config
  5. 5 Verify all settings are configured correctly
